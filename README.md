# Muse Companion Relay（酒馆陪看中转）

SillyTavern / TauriTavern 前端扩展。你和角色每发完一条消息，它就把这条
消息的文字转发到你自己的服务器收件箱，让 Muse 能实时跟上剧情，不用截图。

## 安装

在酒馆里打开「扩展 → 安装扩展」，填入本仓库地址：

```
https://github.com/Asriel134/muse-companion-relay
```

TauriTavern（TT 酒馆）同样适用：在应用内用 Git 链接安装即可。

## 设置

装好后在扩展设置里找到「Muse 陪看中转」：

- 开关：随时开/关，关掉立即停止发送。
- 服务器收件箱地址：默认已填好机主的服务器地址。
- 口令：填服务器上约定的口令（只存在设置里，不写进代码）。

设置区还有一个「发一条测试消息」按钮，用来验证链路是否通。

## 它发送什么

- 发送：聊天编号、角色名、谁说的话、文字内容、时间。
- 不发送：模型 API 密钥、账号密码、酒馆之外的任何数据。

## 工作原理

监听酒馆的消息事件（MESSAGE_SENT / MESSAGE_RECEIVED / CHAT_CHANGED），
读取刚完成的那条消息，POST 到收件箱接口。已按 TauriTavern 的窗口化
加载做了兼容（前端只保留最近若干条消息时也能取到最新一条）。
